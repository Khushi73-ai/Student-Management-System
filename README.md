# Student Management System

## Description
A console-based Student Management System developed using Python and SQLite. It allows users to manage student records through a menu-driven interface.

## Features
- Add Student
- View Student
- Update Student
- Delete Student
- Search Student

## Technologies Used
- Python
- SQLite

## Concepts Used
- CRUD Operations
- SQL Queries
- Parameterized Queries
- Functions
- Modular Programming

## Project Structure

Student-Management-System/
├── main.py
├── database.py
└── README.md

## How to Run

1. Clone or download the project.
2. Run `main.py`.
3. Select an option from the menu.
